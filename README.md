## Overview

Attract-Mode is a cross-platform, full-screen emulator frontend designed for kiosk and living-room setups where a mouse and keyboard are impractical. Its Squirrel-scripted theme engine supports animated layouts, video previews, and scrolling game artwork, while comprehensive emulator integration covers RetroArch, MAME, and any command-line emulator.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Attract-Mode** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Animated Themes** | Squirrel-scripted layouts with custom animations and transition effects |
| **Video Previews** | Per-game video preview playback during library navigation |
| **Multi-Emulator** | Supports RetroArch, MAME, and any emulator with a command-line interface |
| **Kiosk Mode** | Full-screen operation with input lockdown for public cabinet deployments |
